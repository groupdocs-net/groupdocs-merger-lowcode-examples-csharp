# Remove Specific Pages

Pass the numbers of the pages to remove. Page numbers start at 1. The following example removes pages 2 and 4 from an 18-page document.

## Code Example

```csharp
using System;
using GroupDocs.Merger.Domain.Options;
using GroupDocs.Merger.LowCode;

// Load license keys
var publicKey = Environment.GetEnvironmentVariable("GD_PUBLIC_KEY");
var privateKey = Environment.GetEnvironmentVariable("GD_PRIVATE_KEY");

// Apply the license
License.Set(publicKey, privateKey);

// Remove pages 2 and 4
var remover = new RemovePagesPdf("business-plan.pdf", new RemoveOptions(new[] { 2, 4 }));

// Save the remaining pages
remover.Save("output/trimmed.pdf");
```

## How to Run

1. Install the .NET SDK for `net10.0`.
2. Set the `GD_PUBLIC_KEY` and `GD_PRIVATE_KEY` environment variables to your license keys.
3. Open this directory and run the example:
   ```bash
   dotnet run
   ```

## Input Files

- `business-plan.pdf`
